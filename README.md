# 重庆山城之旅 · 8天7晚全家自由行互动地图导览 (Chongqing Family Travel Companion)

> **为“全家游重庆”量身定制的交互式地理地图与随身行程助手**  
> 彻底解决原行程 PDF “看不清实际距离、不了解山城3D台阶高差、无法一览每天路线连线”的痛点！

## 🌟 核心解决的痛点与特色功能

### 1. 空间距离透视 (解决“不知道景点之间有多远”)
原 PDF 为单页幻灯片，无法直观感受重庆的真实空间跨度。本系统将 19 个站点划分为三大清晰空间层级：
* **🏙️ 主城核心半岛圈（Days 1, 2, 6, 7, 8）**：
  * 解放碑、十八梯、洪崖洞、朝天门来福士、长江索道、李子坝、磁器口。
  * **实测距离**：各点之间仅 **0.3 km ~ 15 km**，滴滴车程通常在 10 ~ 30 分钟。
* **🗿 西线世界文化遗产（Day 3）**：
  * 大足石刻·宝顶山。
  * **实测距离**：离开主城向西穿越丘陵，单程 **125 km**，高速车程约 **2 ~ 2.5 小时**（推荐商务包车往返）。
* **❄️ 东南喀斯特雪山仙境（Days 4 ~ 5）**：
  * 武隆仙女山高山滑雪场与大草原。
  * **实测距离**：沿乌江峡谷向东南一路盘升至海拔 1900 米，单程 **195 km**，车程约 **3.5 ~ 4 小时**（建议宿山上高山度假酒店）。
* **✈️ 机场枢纽（Day 8）**：
  * 解放碑至江北国际机场 T3 航站楼约 **27 km**，平峰滴滴车程约 40 ~ 50 分钟。

### 2. 8天行程逐日高亮连线 (Interactive Day-by-Day Highlighting)
* 顶部设有 **Day 1 至 Day 8 快速切换轴** 以及 **“宏观全景”** 选项。
* 选中某一天时：
  * 地图自动平滑缩放至当日最佳视野；
  * 景点间自动绘制发光脉冲虚线与行进方向；
  * 线路上清晰标注每一程的 **实测距离与交通耗时**（例如：`🚗 3.5 km · 滴滴 15-20 分钟`）；
  * 右上角浮动 HUD 实时显示当天累计里程、交通策略与长辈体力负荷评级。

### 3. 景点详情抽屉 (Stop Details Drawer)
点击地图上的任意圆点标记或左侧卡片，右侧即刻滑出丰富详情：
* **📸 看什么**：核心看点、文化典故与最佳人像机位。
* **🥢 吃什么**：地道美食推荐、招牌必点菜品、辣度提示。
* **🚕 怎么去**：最优直达交通方案、少走陡坡路线、地铁 vs 滴滴对比。
* **👵 长辈关怀贴士**：专门针对长辈的防累秘笈（避开上山台阶、无障碍电梯位置、茶馆歇脚点、高山防寒、防踩坑提示）。
* **📋 一键复制打车中文名**：点击即可复制规范的 POI 地址（如 `渝中区较场口十八梯传统风貌区`），可直接粘贴至高德地图或滴滴出行！
* **🧭 外部导航联动**：一键调起外部地图导航。

### 4. 专为长辈定制的“山城 8 大黄金舒适法则”
1. **十八梯必须“从上往下逛”**：导航至【较场口入口（上半城）】，顺坡向下漫步省力，逛到底部打车离开，切忌从下往上爬。
2. **洪崖洞拒绝挤楼内狭窄楼梯**：千厮门大桥平坦人行道或对岸嘉滨路远眺，全景最震撼且完全不挤。
3. **火锅必点“鸳鸯锅”**：清汤选菌菇/骨汤，红汤交代“微辣微微辣”；香油碟包裹降温保护长辈肠胃。
4. **仙女山防寒与雪圈玩法**：海拔近2000米备好防滑雪地靴、羽绒服与墨镜；长辈首选安全的“雪上飞碟（雪圈）”，坐享欢笑不伤膝盖。
5. **大足石刻配导览与电瓶车**：租用语音导览器听生动典故，景区内乘无障碍电瓶车。
6. **4人家庭出行首选滴滴/包车**：避开重庆深层地铁站数以百计的换乘台阶。
7. **长江索道提前线上预约**：微信提前取号免去现场排队 1-2 小时，60岁以上持身份证享长者优惠。
8. **机场T3可申请爱心轮椅服务**：国际航班出境提前3小时到场，航站楼较大可免费申请地勤协助推行。

## 🚀 本地运行与出游随身携带

### 方式 1：Windows 一键快速启动（推荐）
直接在项目根目录下双击运行：
```bat
start-server.bat
```
系统将自动启动轻量 Web 服务器并在默认浏览器打开 `http://localhost:8080`。

### 方式 2：Python 命令行运行
```bash
python serve.py
```

### 方式 3：如何在手机上边走边看（随身地图伴侣）
1. 确保手机与电脑连接在同一 WiFi（例如酒店 WiFi 或手机热点）。
2. 在电脑命令行运行 `ipconfig` 查看电脑局域网 IP（例如 `192.168.1.5`）。
3. 手机浏览器打开 `http://192.168.1.5:8080`，即可像 App 一样在旅行途中随时使用！
4. 点击顶栏 **“📍 我的实时位置”**，手机 GPS 将在重庆地图上实时打点，直观显示你与下一个景点的相对位置。
